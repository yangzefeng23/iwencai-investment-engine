⚡ 四种分析模式

覆盖投资决策
全生命周期

持仓复盘 · 买卖决策 · 宏观分析 · 个股研究。情绪刹车全局优先执行，确保每个分析都基于理性判断。

Mode A
持仓复盘
Portfolio Review
全量持仓健康诊断，三色信号（🟢🟡🔴）综合评估行情、财务、机构三维度，联动语雀历史记录。
复盘 持仓情况 仓位健康 看看我的仓
1用户实时输入持仓（标的 + 比例 + 均价）
2语雀检索各标的历史分析结论
3逐标的拉取行情/财务/机构评级
4输出三色信号健康度表 + 整体小结
Mode B
买卖决策
Trade Decision
五维分析框架按需展开 2-4 个维度，必写最强反对意见，结合语雀历史逻辑保持决策一致性。
买 / 卖 加仓 / 减仓 止损 / 割 要不要
1情绪刹车检测 + 语雀历史操作逻辑
2行情/财务/机构/公告/新闻五路数据
3五维框架选取 2-4 个最相关维度分析
4综合判断（支持/谨慎/反对）+ 必写反对意见
Mode C
宏观分析
Macro Analysis
宏观事件传导链分析，评估持仓所在行业的资金流向与估值分位，联动历史相似宏观环境下的应对记录。
宏观 / 政策 消息影响 利好 / 利空 大盘怎么看
1语雀检索相似宏观环境历史应对
2宏观指标时间序列 + 指数近期反应
3持仓行业资金流向 + 估值分位
4输出传导链 + 影响评估 + 动作优先级
Mode D
个股研究
Stock Research
最全面的分析模式，10 步全维度数据编排，从基础资料到机构评级，生成标准化深度研究报告。
研究 / 深挖 帮我分析 生成研报 帮我看看这只股
1基础资料 + 行情全貌（52周区间）
2财务三视角（利润表/资产负债/估值）
3机构评级 + 公告 + 深度研报 + 新闻
4行业背景 + 语雀历史研究记录

⚙️ 工作原理

端到端
数据流

从用户输入到分析报告输出，六个关键节点，市场数据与知识库双轨并行。

①

CLAUDE.md 路由规则匹配 → 激活 investment-engine Skill

检测用户输入的关键词，匹配四种模式触发词（持仓相关/买卖操作/宏观事件/个股研究），激活对应 Skill 注入上下文。

②

情绪刹车检测（全局前置）

检测追涨/恐慌/FOMO 等情绪信号 → 检测到则暂停分析，输出情绪隔离提问，等用户理性确认后继续。

③

语雀知识库检索（前置步骤）

yuque_search 提取历史分析结论和操作逻辑，注入分析上下文；忽略持仓数量/成本价等时效性数据。

④

按模式并发/串行调用 iwencai Skills

数据查询类 → /v1/query2data（结构化数据表格）· 资讯搜索类 → /v1/comprehensive/search（新闻/公告/研报列表）· 缺失数据标注「暂无数据」，不中断流程。

⑤

综合分析 → 输出结构化报告

市场数据 + 语雀历史经验 → 应用对应分析框架 → 生成 Markdown 报告，末尾标注「数据来源：同花顺问财」。

⑥

询问写回语雀 → 用户确认 → 5步写回流程

get_toc 获取目录结构 → update_toc 按需创建目录节点 → create_doc 新建文档 → update_toc 挂载 → 返回文档 URL。

🚀 快速开始

三步启动
投资分析引擎

无需服务器，无需数据库。全部能力通过 Claude Code 配置文件实现，轻量、安全、可持续。

1

配置环境变量

复制 .env 模板，填入同花顺问财 API Key 和语雀知识库信息。

# 复制模板 cp .env.example .env # 填入你的配置 IWENCAI_API_KEY=your_key_here YUQUE_NAMESPACE=user/book-slug YUQUE_ARCHIVE_DIR=投资分析资产库
2

配置 MCP Server

在 Claude Code 中启用 yuque-mcp，用于语雀知识库的读写操作。

# Claude Code MCP 配置 "yuque-mcp": { "command": "npx", "args": ["yuque-mcp"], "env": { "YUQUE_TOKEN": "your_token" } }
3

开始分析

在 Claude Code 中打开此项目，直接用自然语言触发分析引擎即可。

# 示例触发语句 "帮我看看我的持仓情况" "光迅科技值不值得持有" "美联储降息对我的仓位影响" "深度研究宁德时代"
