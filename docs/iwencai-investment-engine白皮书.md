# iwencai-investment-engine 白皮书

**版本：** v1.0  
**日期：** 2026-04-16  
**数据来源：** 同花顺问财 OpenAPI

---

## 一、概述

本项目共集成 **15 个 Skill**，全部基于同花顺问财（iwencai）的 OpenAPI 构建，统一使用 Bearer Token 认证（环境变量 `IWENCAI_API_KEY`），统一入口域名 `https://openapi.iwencai.com`。

Skill 按功能分为三大类：

| 类别 | 数量 | 核心能力 |
|------|------|---------|
| **数据查询（Query）** | 7 | 结构化查询特定标的/指标的精确数据 |
| **智能筛选（Selector）** | 5 | 通过多条件自然语言从全市场过滤符合要求的标的 |
| **资讯搜索（Search）** | 3 | 全文检索公告、研报、新闻等非结构化内容 |

---

## 二、数据查询 Skill（Query 型）

> 共同特征：调用 `POST /v1/query2data`，支持 `page`/`limit` 分页，返回 `datas[]` + `code_count`。

### 2.1 行情数据查询 · `hithink-market-query`

**能力边界**

查询股票、ETF、指数的实时及历史行情，覆盖价格、涨跌幅、成交量、资金流向、技术指标（MACD/KDJ/RSI/布林线）。

**典型问句**
```
同花顺今日最新价格是多少？
上证指数主力资金流向
近一周换手率最高的股票
```

---

### 2.2 财务数据查询 · `hithink-finance-query`

**能力边界**

查询全市场个股财务报表数据：营业收入、净利润、毛利率、净利率、ROE、ROA、负债率、现金流、PE/PB/PS 等估值指标。

**典型问句**
```
同花顺近三年净利润趋势
ROE 最高的 A 股公司有哪些？
负债率低于 30% 的消费类公司
```

---

### 2.3 基本资料查询 · `hithink-basicinfo-query`

**能力边界**

查询全品类标的的静态基础信息：股票上市日期/所属行业、基金管理人/费率、期货合约到期日/交割方式、可转债评级/正股信息、债券发行主体/票面利率。

**典型问句**
```
同花顺的上市日期是哪天？
华夏沪深300ETF 的管理费率是多少？
螺纹钢主力合约的交割方式？
```

---

### 2.4 宏观数据查询 · `hithink-macro-query`

**能力边界**

查询宏观经济指标时间序列：GDP、CPI、PPI、M2、PMI、社融、LPR、汇率、工业增加值、进出口等。

**典型问句**
```
2024 年中国 GDP 增速是多少？
最近一期 CPI 同比数据
LPR 利率历史走势
```

---

### 2.5 指数数据查询 · `hithink-zhishu-query`

**能力边界**

查询 A 股、港股、美股主要指数（上证/深证/创业板/沪深300/中证500/恒生/纳斯达克/道琼斯）的点位、涨跌幅、成交量等行情数据。

**典型问句**
```
今日沪深 300 涨跌幅
创业板指最新成交量
纳斯达克近一个月走势
```

---

### 2.6 机构研究与评级查询 · `hithink-insresearch-query`

**能力边界**

查询机构观点类数据：券商研报评级（买入/增持/中性/卖出）、盈利预测、ESG 评级、信用/主体评级、基金星级评定、券商金股推荐。

**典型问句**
```
同花顺最新研报评级
被多家机构评为"买入"的公司有哪些？
券商本月金股推荐名单
```

---

### 2.7 期货期权数据查询 · `hithink-futures-query`

**能力边界**

查询期货期权专项数据：行情（价格/涨跌幅）、隐含/历史波动率、库存/产销、会员持仓排行、行权价/行权量等。

**典型问句**
```
沪铜主力合约最新行情
50ETF 期权隐含波动率
螺纹钢期货会员持仓前十排名
原油期货库存数据
```

## 三、智能筛选 Skill（Selector 型）

> 共同特征：自然语言 → Query 改写 → `POST /v1/query2data` → 空数据时最多重试 2 次逐步放宽条件。结果**强制以表格展示**。

### 3.1 问财选 A 股 · `hithink-astock-selector`

**筛选维度**

行情指标（价格/涨跌幅/成交量）× 技术形态（均线多头/突破新高/K 线形态）× 财务指标（PE/PB/利润）× 行业概念（科技/医药/消费）

**典型用法**
```
今日涨幅超过 5% 的 A 股
ROE 大于 15% 且市值 200 亿以下的医药股
均线多头排列的科技板块股票
```

---

### 3.2 问财选 ETF · `hithink-etf-selector`

**筛选维度**

行情（价格/涨跌幅）× 跟踪指数（沪深300/中证500/创业板）× 规模（资产规模/份额变化）× 基本面（费率/跟踪误差）× 风格（成长/价值）

**典型用法**
```
规模最大的沪深 300 ETF 有哪些？
费率低于 0.1% 的股票 ETF
最近一个月份额增长最多的 ETF
```

---

### 3.3 问财选港股 · `hithink-hkstock-selector`

**筛选维度**

行情 × 财务（市盈率/市净率/营收）× 行业概念 × 陆港通（北向/南向持股）

**典型用法**
```
港股科技股市盈率低于 20 的有哪些？
南向资金近一周净买入最多的港股
腾讯、阿里巴巴等蓝筹股行情
```

---

### 3.4 问财选美股 · `hithink-usstock-selector`

**筛选维度**

行情 × 财务（PE/PB/营收/利润）× 行业概念 × 业绩预测（盈利增速）× 研报评级（买入/增持）

**典型用法**
```
评级"买入"的美股科技公司
市盈率低于 20 且盈利增速超 20% 的美股
近一周涨幅前 10 的美股
```

---

### 3.5 问财选板块 · `hithink-sector-selector`

**筛选维度**

行业估值（PE/PB/估值分位）× 资金流向（主力净流入/北向资金）× 涨跌幅排名 × 板块类型（行业/概念/地域）× 成交额/换手率

**典型用法**
```
今日涨幅最大的 5 个行业板块
主力资金净流入前 10 的概念板块
半导体板块当前估值分位数
```

## 四、资讯搜索 Skill（Search 型）

> 共同特征：调用 `POST /v1/comprehensive/search`，`app_id` 固定为 `AIME_SKILL`，通过 `channels` 区分内容类型。

### 4.1 新闻搜索 · `news-search`

**接口参数**：`channels: ["news"]`

**能力边界**

全文检索财经新闻，覆盖官媒、主流财经媒体（证券时报/经济观察报等）、行业垂直网站、上市公司官网等。

**典型用法**
```
DeepSeek 最近有什么新闻？
央行最新货币政策动态
新能源汽车行业近一周重要新闻
特斯拉的业务进展有哪些？
```

---

### 4.2 公告搜索 · `announcement-search`

**接口参数**：`channels: ["announcement"]`

**能力边界**

检索 A 股、港股、基金、ETF 上市主体发布的公告，支持：定期财务报告（年报/季报）、分红派息、回购增持计划、资产重组、重大合同、业绩预告等所有公告类型。

**典型用法**
```
贵州茅台最近一个月有哪些公告？
最近有哪些公司发布回购计划？
宁德时代的业绩预告
中国平安的分红公告
```

---

### 4.3 研报搜索 · `report-search`

**接口参数**：`channels: ["report"]`

**能力边界**

专门检索主流投研机构（证券公司/基金公司/独立研究机构）发布的研究报告，聚焦提取：分析逻辑、投资评级、目标价、风险提示。

**典型用法**
```
人工智能行业的最新研究报告
特斯拉的投资评级和目标价是多少？
芯片行业深度分析报告
医药行业投资前景报告
```

## 五、技术规格摘要

### 5.1 统一认证

```bash
# 所有 Skill 共用同一环境变量
export IWENCAI_API_KEY="your_api_key_here"
```

### 5.2 两套 API

| API | 路径 | 用途 | 典型 `channels` |
|-----|------|------|----------------|
| 结构化数据 | `/v1/query2data` | Query + Selector 型 | 无 |
| 全文搜索 | `/v1/comprehensive/search` | Search 型 | `news` / `announcement` / `report` |

### 5.3 分页机制（Query/Selector 型）

```
默认每页 10 条，page 从 1 开始
code_count > len(datas) 时说明有更多结果
需要全量数据时循环递增 page 至取完
```

### 5.4 容错策略

| Skill 类型 | 无数据时的处理 |
|-----------|--------------|
| Query 型 | 不重试，直接引导用户访问同花顺问财 Web 端 |
| Selector 型 | 自动放宽条件重试最多 2 次，最终说明实际使用的查询语句 |
| Search 型 | 不重试，返回空结果并给出友好提示 |

## 六、Skill 选择决策树

```
用户问题
├── 涉及"选什么/筛什么"
│   ├── A 股           → hithink-astock-selector
│   ├── 港股           → hithink-hkstock-selector
│   ├── 美股           → hithink-usstock-selector
│   ├── ETF            → hithink-etf-selector
│   └── 板块           → hithink-sector-selector
│
├── 涉及查具体数值
│   ├── 实时行情/资金流  → hithink-market-query
│   ├── 财报/利润/ROE   → hithink-finance-query
│   ├── 上市日期/费率等  → hithink-basicinfo-query
│   ├── GDP/CPI/利率    → hithink-macro-query
│   ├── 指数点位/涨跌幅  → hithink-zhishu-query
│   ├── 券商评级/ESG    → hithink-insresearch-query
│   └── 期货/期权行情    → hithink-futures-query
│
└── 涉及"搜文章/找资料"
    ├── 最新新闻/政策    → news-search
    ├── 公司公告/年报    → announcement-search
    └── 投研报告/评级    → report-search
```

## 七、组合使用示例

### 场景一：深度研究一只股票

| 步骤 | Skill | 目的 |
|------|-------|------|
| 1 | `hithink-basicinfo-query` | 查上市日期、所属行业 |
| 2 | `hithink-finance-query` | 查近 3 年财务指标 |
| 3 | `hithink-market-query` | 查最新行情和资金流向 |
| 4 | `hithink-insresearch-query` | 查券商评级和盈利预测 |
| 5 | `announcement-search` | 查最新公告（回购/分红/业绩预告）|
| 6 | `report-search` | 查机构深度研报 |

### 场景二：宏观驱动选股

| 步骤 | Skill | 目的 |
|------|-------|------|
| 1 | `hithink-macro-query` | 确认宏观环境（CPI/PMI/社融）|
| 2 | `hithink-sector-selector` | 筛资金流入的行业板块 |
| 3 | `hithink-astock-selector` | 在目标板块内筛满足财务条件的个股 |
| 4 | `news-search` | 验证行业近期是否有利空事件 |
